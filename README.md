## 🧑‍💻 Sobre mim

Sou desenvolvedor back-end com foco em Python, especializado na construção de APIs RESTful robustas e bem estruturadas. Tenho experiência com frameworks como **FastAPI** e **Django**, modelagem de banco de dados com **PostgreSQL** e **SQLAlchemy**, testes automatizados com **pytest** e conteinerização com **Docker**.

Gosto de escrever código limpo, de fácil manutenção e orientado a boas práticas.
